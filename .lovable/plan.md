# منصة تدريب متكاملة (Training Platform)

منصة تعليمية عربية (RTL) يرفع فيها المالك الفيديوهات والدورات، ويتعلم منها المتدرب، مع مساعد ذكاء اصطناعي، اختبارات مصححة آلياً، ولوحة تحكم واسعة الصلاحيات — كتطبيق PWA سريع ونظيف.

## الهوية البصرية
- لوغو مخصص (رمز تجريدي يجمع "شعلة معرفة + إشارة تقدّم") بنسخ فاتحة/داكنة، وأيقونات التطبيق للـ PWA.
- نظام تصميم كامل بالتوكنز: لون أساسي عميق (أزرق-أخضر تعليمي)، لون تمييز دافئ، تدرجات وظلال ناعمة، زوايا معتدلة.
- خطوط عربية حديثة (عناوين + نص) مع دعم RTL كامل، وضع ليلي/نهاري.
- واجهة واقعية عملية: شريط جانبي، بطاقات دورات، مشغّل فيديو بتصميم مخصص، حالات فارغة ورسوم متحركة خفيفة.

## الأدوار والصلاحيات
- المالك (Owner): صلاحيات كاملة — إدارة المستخدمين والأدوار، الدورات، الاختبارات، الشهادات، الإعدادات، الإعلانات، التقارير، الاشتراكات، سجل النشاط.
- مدرّب (Instructor): إنشاء وتحرير دوراته ودروسه واختباراته ومتابعة متدربيه.
- مشرف (Moderator): مراجعة المحتوى، الأسئلة، التعليقات.
- متدرب (Student): التعلّم، الاختبارات، الشهادات، النقاش.
- الأدوار تُخزَّن في جدول مستقل مع فحص أمني على مستوى قاعدة البيانات (لا تُخزن على الملف الشخصي).

## الوظائف الرئيسية
1. الحسابات: تسجيل دخول بالبريد/كلمة المرور، ملف شخصي، صورة، تغيير كلمة المرور، دعوة مستخدمين.
2. الدورات: تصنيفات، وسوم، مستويات، وصف، صورة غلاف، سعر/مجاني، حالة (مسودة/منشورة/مؤرشفة).
3. البنية: دورة → أقسام → دروس (فيديو، مستند PDF، نص، رابط، اختبار).
4. رفع الفيديو والملفات إلى تخزين سحابي، مشغّل مع متابعة زمن المشاهدة، استئناف من آخر نقطة، سرعة التشغيل، ملاحظات موقوتة.
5. التقدّم: نسبة الإنجاز لكل درس/دورة، شرط إكمال متسلسل اختياري، سجل نشاط يومي وسلسلة أيام (Streak).
6. الاختبارات والواجبات:
   - أنواع أسئلة: اختيار متعدد، صح/خطأ، إجابة قصيرة، مقالي، رفع ملف.
   - إعدادات مرنة: مؤقّت، عدد المحاولات، درجة النجاح، خلط الأسئلة، إظهار الإجابات.
   - تصحيح تلقائي للموضوعي + تصحيح بالذكاء الاصطناعي للمقالي مع تعليقات وتغذية راجعة، وإمكانية تعديل المدرّس للدرجة.
   - تفعيل/تعطيل الاختبار لكل دورة (اختياري بالكامل).
7. الشهادات: توليد شهادة إتمام برقم تحقق وصفحة تحقق عامة.
8. المساعد الذكي (Lovable AI):
   - دردشة مساعدة داخل الدرس تفهم سياق الدرس.
   - توليد ملخصات ونقاط رئيسية وبطاقات مراجعة من محتوى الدرس.
   - توليد مسودة أسئلة اختبار للمدرّب.
   - تصحيح المقالي وإعطاء تغذية راجعة.
   - توصية بمسار تعلّم للمتدرّب.
9. التفاعل: أسئلة وأجوبة تحت الدرس، تعليقات، تقييم الدورة بالنجوم، إعلانات من المالك، إشعارات داخل التطبيق.
10. التلعيب: نقاط، شارات، لوحة صدارة.
11. لوحة تحليلات: عدد المتدربين، الإكمال، متوسط الدرجات، أكثر الدروس مشاهدة، تقارير قابلة للتصدير CSV.
12. الإعدادات العامة: اسم المنصة، اللوغو، الألوان، اللغة، صفحة "من نحن"، سياسات.
13. PWA: قابل للتثبيت مع مانيفست وأيقونات (تثبيت على الشاشة الرئيسية دون كسر المعاينة).

## الخريطة (المسارات)
```text
/                 الصفحة الرئيسية التعريفية
/auth             دخول / تسجيل
/courses          استعراض الدورات + بحث وفلاتر
/courses/$slug    تفاصيل الدورة
/learn/$courseId/$lessonId   مشغّل التعلّم
/quiz/$attemptId  خوض الاختبار
/dashboard        لوحة المتدرب (تقدمي، شهاداتي)
/certificates/$code  تحقق عام
/admin            لوحة المالك: نظرة عامة
/admin/courses    إدارة الدورات والدروس والرفع
/admin/quizzes    إدارة الاختبارات والتصحيح
/admin/users      المستخدمون والأدوار
/admin/analytics  التحليلات
/admin/settings   الإعدادات والإعلانات
```

## التفاصيل التقنية
- تفعيل Lovable Cloud: قاعدة بيانات PostgreSQL + مصادقة + تخزين للفيديو والملفات.
- الجداول: profiles, user_roles, categories, courses, sections, lessons, enrollments, lesson_progress, quizzes, questions, question_options, quiz_attempts, attempt_answers, assignments, certificates, reviews, qna_threads, qna_replies, announcements, notifications, badges, user_badges, activity_log, platform_settings.
- كل جدول مع GRANTs + RLS دقيقة حسب الدور، ودالة `has_role` من نوع security definer.
- الذكاء الاصطناعي عبر Lovable AI باستخدام `google/gemini-3.7-flash` داخل دوال خادمية فقط (المفتاح لا يصل للمتصفح).
- المشاهدة والتقدّم تُحفظ في القاعدة، والرفع عبر التخزين السحابي مع سياسات وصول.
- بيانات تجريبية أولية (دورة + دروس + اختبار) لتظهر الواجهة حية من أول لحظة.

## خطة التنفيذ على مراحل
1. الهوية والتصميم: اللوغو، التوكنز، RTL، الهيكل العام والصفحة الرئيسية.
2. Cloud + المصادقة + الأدوار + الملفات الشخصية.
3. الدورات والدروس والرفع + لوحة المالك.
4. مشغّل التعلّم والتقدّم والتسجيل بالدورات.
5. الاختبارات + التصحيح الآلي + التصحيح بالذكاء الاصطناعي.
6. المساعد الذكي والملخصات والتوصيات.
7. الشهادات، التقييمات، الأسئلة والأجوبة، الإشعارات، التلعيب.
8. التحليلات، الإعدادات، PWA، التلميع النهائي.
