## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- npm أو yarn أو bun

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/abbasfasel2012-source/knowledge-craft-os.git
cd knowledge-craft-os

# تثبيت المكتبات
npm install
# أو
bun install
```

### الإعدادات

```bash
# نسخ ملف الإعدادات
cp .env.example .env.local

# ملء البيانات
# افتح .env.local وأضف:
# - VITE_SUPABASE_URL
# - VITE_SUPABASE_ANON_KEY
# - VITE_AI_API_KEY (اختياري)
```

### التطوير المحلي

```bash
# بدء خادم التطوير
npm run dev

# الدخول إلى
# http://localhost:5173
```

### البناء والنشر

```bash
# بناء الإصدار الإنتاجي
npm run build

# معاينة الإصدار
npm run preview
```

## 📞 الدعم والمساعدة

### المشاكل الشائعة

**المشكلة: Service Worker لا يعمل**
```bash
# الحل:
# 1. تأكد من استخدام HTTPS
# 2. امسح ذاكرة التخزين المؤقت
# 3. جرب في Incognito Mode
```

**المشكلة: الفيديو لا يرفع**
```bash
# التحقق من:
# - حجم الملف (أقل من 2GB)
# - صيغة الملف (MP4, WebM, Ogg)
# - سرعة الإنترنت
```
